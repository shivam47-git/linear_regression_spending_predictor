Project Summary
This project uses linear regression to analyze and predict the yearly spending of e-commerce customers based on their behavior and characteristics. The dataset includes features like average session length, time spent on the app, time spent on the website, and length of membership. The goal is to help the company decide whether to focus on improving their website or mobile app experience.

Steps:
Data Loading & Exploration:

Loaded the dataset using pandas.
Explored the data with info, describe, and head methods.
Visualization:

Used seaborn and matplotlib to visualize relationships between features and yearly spending.
Found that length of membership and time on app have the strongest correlation with yearly spending.
Data Preparation:

Selected relevant features as predictors (X) and yearly amount spent as the target (y).
Split the data into training and testing sets.
Model Training:

Trained a linear regression model using scikit-learn.
Also used statsmodels for a detailed statistical summary.
Evaluation:

Predicted test data and visualized predictions.
Calculated error metrics: Mean Absolute Error, Mean Squared Error, and Root Mean Squared Error.
Analyzed residuals to check model assumptions.
Conclusion:

Length of membership is the most important factor for predicting yearly spending.
Time spent on the app is more influential than time spent on the website.
The company should focus on improving the app experience.

Code Explanation
============================

1. Importing Libraries
	- `pandas as pd`: For handling data (reading CSV, DataFrames)
	- `matplotlib.pyplot as plt`: For plotting graphs
	- `seaborn as sns`: For advanced, pretty plots
	- `pathlib.Path`: For working with file paths

2. Loading the Data
	- Tries to find the dataset (`Ecommerce Customers.csv`) in the same folder as the script
	- If found, loads the data into a DataFrame called `customers`
	- If not found, raises an error

3. Exploring the Data
	- `customers.head()`: Shows the first few rows
	- `customers.info()`: Shows info about columns and data types
	- `customers.describe()`: Shows summary statistics (mean, std, etc)

4. Visualizing Relationships
	- Uses seaborn to plot relationships between features and the target (`Yearly Amount Spent`):
	  - `jointplot` for Time on Website vs Yearly Amount Spent
	  - `jointplot` for Time on App vs Yearly Amount Spent
	  - `pairplot` for all features
	  - `lmplot` for Length of Membership vs Yearly Amount Spent

5. Preparing Data for Machine Learning
	- Selects features (`X`) and target (`y`)
	- Splits data into training and testing sets (70% train, 30% test)

6. Training the Linear Regression Model
	- Creates a `LinearRegression` object
	- Fits the model on the training data
	- Prints the coefficients (weights for each feature)
	- Prints the R² score (how well the model fits the data)

7. Statsmodels OLS Regression (Optional)
	- Adds a constant to the features (for intercept)
	- Fits an Ordinary Least Squares (OLS) regression using statsmodels
	- Prints a detailed summary (coefficients, p-values, etc)

8. Making Predictions
	- Uses the trained model to predict on the test set
	- Plots actual vs predicted values

9. Evaluating the Model
	- Calculates Mean Absolute Error (MAE), Mean Squared Error (MSE), and Root Mean Squared Error (RMSE)
	- These metrics show how far off the predictions are from the actual values

10. Residual Analysis
	 - Calculates residuals (difference between actual and predicted)
	 - Plots the distribution of residuals to check if errors are normally distributed
	 - Plots a probability plot to visually check normality
